Haxbyte is where I write about the enterprise-grade practices I use every day — clean code, fast performance, architecture that doesn't turn into technical debt — applied to smaller, faster-moving projects instead of the ceremony that usually comes with them.

It's build-in-public by design: real projects, real decisions, including the ones that didn't work, aimed at engineers and anyone curious about how the work actually gets done — not a sales pitch. Client-facing and consulting work live somewhere else, under my own name; this is the place for the writing.

Under the hood, it's an Astro site with plain, hand-rolled CSS — no Tailwind, no component library, no animation framework — hosted on Cloudflare's edge network. That's a deliberate choice: full control over a visual system that doesn't read like every other templated site, and a stack simple enough that the site itself is proof of the same discipline I write about.

What's here already: a light/dark theme system with a hand-drawn "pulse-line" signature motif, two real client case studies under Builds, and this blog for build logs and technical notes as they happen. More is coming as I ship it.
