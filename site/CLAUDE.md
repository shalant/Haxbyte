## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Documentation Rule

**Keep docs in sync with code changes.** Whenever the codebase is updated (new pages, routes, collections, content structure, design changes, etc.), update the corresponding documentation in `../docs/` to reflect the current state. This maintains the project docs as the authoritative source of truth for the site's structure and capabilities.
