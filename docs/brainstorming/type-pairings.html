Type audit — Haxbyte

Five display/body pairings, same copy, side by side.

Every card below uses the exact same headline, standfirst copy, and paragraph — only the display and body typefaces change. That's the fairest way to compare: differences you see are the fonts, not the words.

Held constant: the utility face (labels, eyebrows, this sentence) stays IBM Plex Mono across every card, matching the current spec in docs/design-system.md — only the display (headline) and body (paragraph) roles are up for comparison.
